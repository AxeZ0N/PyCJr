Date: 2026-08-26
Scope: spec and lock the S4 sample-based half-cell decoder, fact-check
against the Pi emitter, close the scope.

## Verified this session

- Manual entries 93/94 pinned: biphase polarity (1=HIGH-first,
  0=LOW-first), frame = start + 8 data (LSB first) + odd parity + stop,
  440us cell / 220us half-cell, 5× majority per half-bit-sample, 310us
  post-start-burst wait. manual-verified.
- pycjr.py build_frame source-verified: burst-first start + 310us,
  data LSB-first biphase (1: 62+377us, 0: 220+62+157us), odd parity
  encoded as 9th biphase bit, NO stop burst — parity → 1500us frame
  gap. Byte-consistent with the spec.
- Edge-gap classification retired as a decode primitive. The 157us 0→1
  inter-bit gap fuses below the pinned (170,175]us AGC fuse band;
  the edge sequence is structurally lossy. Intra-bit mid-cell biphase
  transition is the only reliable decode axis.
- S4 spec locked: sample-based half-cell decoder, KBDNMI-verbatim core,
  5× majority (not 1×), CH0-latched 220us grid, 310us start phase,
  odd parity, stop never sampled. Target = Pi emitter's actual frame.
- Bare-8 ceiling recalculated: ~185-199 ch/s (~3.5-3.8×), superseding
  the ~2× framing_only_2x estimate. S5 horizon, not S4.
