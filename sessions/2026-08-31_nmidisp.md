# Session — NMIDISP dispatch probe (Probe A)

Date: 2026-08-31
Scope: verify that a custom INT 02h vector installed from the BASIC
bridge is actually dispatched on a real keyboard NMI and returns clean.

## Verified this session

- NMIDISP built via `jr build` stage 0 (lint-toggle path), 72 bytes,
  disasm reviewed. Installer entry 0E 1F 55 06; selfloc `lea bp,[bp+0x75]`
  -> entry+128; handler offset 0x2E (`lea bx,[bp-0x52]`); handler
  selfloc `lea bp,[bp+0x4A]` -> entry+128; installer tail 07 5D CB;
  handler tail 5D 58 1F CF.
- Hardware pass: Loaded 72, RETURNED OK, dispatch flag=1 on a single IR
  keystroke. Keyboard dead (KBDNMI replaced, expected). Cursor blinking
  (IF restored, timer IRQ alive). Clean run per contract.
- Control run with no keystroke: dispatch flag=0, clean. No spurious
  NMI fired in the window.
- IRPING2 status=3 passed before each run; transport sanity established.
