# Sessions

One file per scope: `YYYY-MM-DD_scope.md`. Append-only narrative.

Contents:
- Decisions locked this session (do not re-litigate)
- What was built / tested / observed
- Loose ends + contingencies
- Next-session pointer

The newest file is the handoff. Paste it (plus `git log --oneline -20`)
at the start of a new session.
